## 独立した CLI の検証で見つかった共有実行時の修正（2026-10-17）

`dev` のコミット `3f0ef25` に基づく候補ブランチ `fix/cli-discovered-runtime-bugs` のローカル結果です。PR の正確な先頭コミットのホスト型検査は別です。この変更は、元のアプリケーションに独立した CLI やサブスクリプションのプロバイダーを追加するものではありません。

- HTTP カスタムツールは、`Manager.ProxyAddr` が返す完全な記録プロキシ URL を使います。以前は `"http://" + addr` がテスト用の `http://127.0.0.1:<port>` を `http://http://127.0.0.1:<port>` に変え、到達前に失敗しました。現在は `proxyStr = addr` で保持します。実際の直接接続、明示設定、自動プロキシの各経路が合格し、自動経路は修正前に失敗しました。
- 起動時に既存の会話記録パスがディレクトリかを先に確認します。Windows の通常ファイルの回帰テストは修正前に失敗し、現在はファイルを保持してパスを拒否します。存在しないディレクトリは引き続き有効です。新しい診断を英語・韓国語・簡体字中国語で用意しました。
- 終了時は作業を中止し、HTTP を排出した後、受け入れ済みのチャット、補足の回答、チェックポイント公開を待ってストアを閉じます。以前は HTTP の排出だけでは、DB を閉じた後に背景の終了処理が書き込めました。最終スナップショット・コンテキストの書き込みエラーは伝播し、保留項目を保持して終了を明示的に失敗にします。削除済み・競合レコードは無害として扱います。この限定した排出は、全スケジューラーやエンジンの生成元を網羅するとは主張しません。
- 中止時の使用量テストは、本番の初期化と同じ既存の任意使用量テーブルを作るよう修正しました。修正前にテーブル不足の失敗を再現し、新しい DB の修正済みテストも正確な使用量のアサーションを保持します。

実際の PostgreSQL の終了確認は、閉じて開き直した際の永続化と最終書き込み失敗の注入を含む 11 テスト・サブテストが合格しました。主プロセスは 4 テストが合格し、正常終了 0、再起動 75、上限付きの失敗、実際にポート使用中で起動失敗した場合の削除処理を確認しました。対象を絞ったプロキシ・起動・ロケール回帰も合格。Windows の全バックエンドは 1,975 合格、2 失敗、15 スキップでした。1 件は未変更のシンボリックリンク作成権限の制限、もう 1 件は新診断 2 件によりカタログ期待値が変わったもので、完全性検査を外さず 1,980 から 1,982 に更新しました。修正版カタログは別途検証しています。残りのプラットフォーム結果は Linux・ホスト型検査が必要です。

<a id="running-database-backed-tests"></a>
## DB を使うテストの実行

`db`、`server`、`agent` は PostgreSQL を必要とします。接続先は環境変数 `ARTEX_TEST_DSN` **のみ**から解決し、アプリ自身の DSN（`ARTEX_PG_DSN` / `config.json`）には戻りません。実行中アプリの本番 DB を `go test` が変更しないための意図した設計です。

- **`ARTEX_TEST_DSN` が未設定** → DB を使うすべてのテストをスキップし、DB には
  触れません。
- **`ARTEX_TEST_DSN` に使い捨て DB を設定** → その DB に対して実行します。
- **`ARTEX_TEST_DSN` がアプリと同じ DB に解決**（同じホスト、
  ポート、DB 名）→ 接続前に `refusing to run tests against the live database; point ARTEX_TEST_DSN at a throwaway DB` で即座に失敗します。

最も簡単な実行方法:

```bash
make test-db
```

`make test-db`（`scripts/test-db.sh`）は、`sw_user_test` 所有の `scopeweaver_test_<pid>` を作成し、`ARTEX_TEST_DSN` を向け、`go test ./db/ ./server/ ./agent/ -count=1` を実行して、失敗時も終了時に削除します。ローカル PostgreSQL に合わせて `TEST_DB_ROLE`、`TEST_DB_HOST`、`TEST_DB_NAME` を上書きできます。DB 名は `scopeweaver_test_`（アダプター E2E は `scopeweaver_adapter_`）で始めてください。

自分で管理する DB で一部だけ実行する場合、`ARTEX_TEST_DSN` を設定し `go test` を直接呼びます:

```bash
export ARTEX_TEST_DSN='postgres://sw_user_test@/scopeweaver_test_1?host=/tmp&sslmode=disable'
go test ./server/ -run TestSomething -count=1
```
